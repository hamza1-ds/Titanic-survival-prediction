# Titanic Survival Prediction 🚢

A machine learning project that predicts whether a passenger survived the Titanic disaster.

## Project Overview
- Cleaned and prepared real Titanic passenger data
- Performed Exploratory Data Analysis (EDA)
- Built and compared two ML models

## Models Used
- Logistic Regression — 80% accuracy
- Decision Tree — 80% accuracy

## Tools & Libraries
- Python
- Pandas
- Matplotlib & Seaborn
- Scikit-learn

## Project Steps
1. Load & explore data
2. Clean missing values
3. EDA with visualizations
4. Train models
5. Evaluate & compare results

## Key Findings
- Female passengers had a 74% survival rate vs 19% for males
- 1st class passengers survived at 63% vs 24% for 3rd class
- Both models achieved 80% accuracy on test data
